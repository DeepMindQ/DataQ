Before delivery begins

How an engagement starts

One page, signed in week two: the metric the program must move, the owner of each control, and the boundaries of acceptable risk. Your board and your auditors read the same page delivery runs on.

A named business metric

Every engagement starts with the number you need to move. It is agreed before work begins and reported every fortnight.

A named control owner

One accountable person on each control, never a committee. When your auditor asks who signed, the trail has a name.

A named risk boundary

The boundaries of acceptable risk are fixed at the start. Inside them, teams move fast. Outside them, nothing ships.

Program charter — one page

Metric: the number the program must move, signed as baseline

Control owner: one accountable name per control
